# kapunahelewong.github.io

A minimal, custom-built portfolio site showcasing my work in documentation, open-source contributions, and developer tools.

**[View the site →](https://kapunahelewong.github.io/)**

## What's here

A 3×3 grid of projects and contributions:

- **Builder Docs** — Comprehensive developer documentation for Builder.io
- **Angular** — Official Angular docs and 70+ sample applications
- **Pepa** — Open-source documentation platform (MDX + OpenAPI + MCP)
- **GitHub & Stripe API Explorers** — Static reference sites built from OpenAPI specs
- **Bazel** — Contributor to the docs migration project
- **Aspect** — Python and JavaScript documentation for Bazel
- **Speaking** — Selected talks and presentations

Plus a [blog](/posts) exploring documentation, information architecture, and developer experience.

## Tech

- **Hugo** — static site generator
- **Custom layouts** — no frameworks, minimal CSS with CSS variables
- **Light mode** — clean, sharp corners, responsive grid (3 cols → 1 col)
- **GitHub Pages** — auto-deployed via GitHub Actions on push to main

## Run locally

```bash
hugo server
```

Then open http://localhost:1313/ in your browser. Hugo watches for changes and live-reloads.
